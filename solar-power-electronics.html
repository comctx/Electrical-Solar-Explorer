MPPT vs. PWM Charge Controllers

MPPT

Uses power electronics to operate the PV array near a useful maximum-power point while converting voltage/current to the battery side.

More flexible
PWM

Connects the array to the battery in a switched manner. Simpler, but array operating voltage is pulled closer to battery voltage during charging.

Simpler
MPPT does not create energy. It converts voltage and current so available PV power can be transferred more effectively under suitable conditions.

PV String & Combiner Concepts

Series modules

Voltages add while string current remains approximately that of one module under matched conditions.

Parallel strings

String currents add while operating voltage remains approximately the same.

Combiner box

Provides a common point for multiple strings and may contain string fuses/breakers, disconnects, surge protection, and monitoring.

Solar Safety

PV modules can produce voltage whenever illuminated, and battery systems can deliver extremely high fault current. Treat PV and battery conductors as potentially energized, use appropriately rated DC equipment, follow manufacturer instructions, and use applicable electrical-code requirements for disconnects, overcurrent protection, grounding/bonding, rapid shutdown, conductor sizing, and equipment locations.
