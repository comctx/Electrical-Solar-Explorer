Beginner Start Here

  1. The PLC repeatedly reads inputs, solves logic, and updates outputs.
  2. A normally-open instruction is true when its referenced bit/input is true.
  3. A normally-closed instruction is true when its referenced bit/input is false.
  4. Series contacts act like AND logic; parallel branches act like OR logic.
  5. A timer can require a condition to stay true for a set time before its done bit turns on.
