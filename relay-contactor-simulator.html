Beginner Start Here

  1. The coil is the electromagnet.
  2. NO contacts close when the coil energizes.
  3. NC contacts open when the coil energizes.
  4. A contactor uses the same idea to switch larger loads such as motors.
  5. The auxiliary contact can hold the circuit on after the Start button is released.

Start / Stop Motor Starter

Press Start. The K1 coil energizes, the main contact closes, the motor runs, and the K1 auxiliary contact seals around the Start button.

Press START to energize the contactor.

What the Seal-In Contact Does

The Start button is momentary. Once K1 energizes, its auxiliary NO contact closes in parallel with the Start button. That creates another path to the K1 coil, so the contactor stays energized after Start is released. Pressing Stop or opening the overload contact breaks the coil circuit.

Safety Note

This is a low-voltage educational simulation. Real motor starters can control hazardous voltage and stored/mechanical energy. Follow manufacturer documentation and qualified-person procedures for real equipment.
