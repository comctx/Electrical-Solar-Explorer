Beginner Start Here

  1. A rectifier lets current flow so the output has one polarity.
  2. Half-wave uses one half of the AC cycle.
  3. Full-wave bridge uses both halves, so ripple happens twice per AC cycle.
  4. A filter capacitor charges near the waveform peak and supplies the load between peaks.
  5. More capacitance or less load current generally means less ripple.
