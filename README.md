# All Things Electrical

**Electrical & Solar Explorer**

All Things Electrical is a broad, practical electrical-learning reference built for both beginners and experienced users. It combines clear explanations, technical detail, diagrams, calculators, simulators, troubleshooting tools, and guided learning paths in one browser-based app.

The project is designed around a simple idea:

> Start simple, then let the user go deeper when they are ready.

## Learning Levels

Many pages use three levels of detail:

- **Beginner** — plain-language explanations and basic concepts
- **Technical** — wiring relationships, terminals, measurements, devices, and system behavior
- **Advanced** — deeper theory, calculations, protection, control, power quality, communications, and troubleshooting

The selected detail level is shared across supported pages.

## Major Topics

The app now covers a wide range of electrical and electronic subjects, including:

- Electrical fundamentals, AC/DC, Ohm's Law, power, and wiring
- Wire, cable, raceways, terminal blocks, lugs, ferrules, splices, and connectors
- Home wiring and wiring diagrams
- Grounding, bonding, shielding, and protection devices
- Lighting, lamps, LED drivers, ballasts, photocells, occupancy sensors, and dimming
- Batteries, charging, power supplies, rectifiers, inverters, and converters
- Transformers, generators, alternators, backup power, ATS systems, and UPS systems
- Power factor, harmonics, capacitor banks, and harmonic filtering
- Protective relaying, substations, reclosers, sectionalizers, and surge protection
- Motors, starters, VFDs, soft starters, servo systems, motion control, and motor protection
- Relays, contactors, sensors, switches, PLCs, ladder logic, and automation
- Machine safety systems, safety relays, light curtains, interlocks, and Safe Torque Off
- SCADA, RTUs, IEDs, industrial Ethernet, Modbus, DNP3, IEC 61850, gateways, and fiber communications
- Electronics including capacitors, inductors, diodes, transistors, thyristors, ICs, op-amps, oscillators, and vacuum tubes
- Test equipment, metering, instrumentation, oscilloscopes, CTs, PTs/VTs, shunts, and transducers
- Heating, cooling, thermal management, RTDs, thermocouples, thermistors, and enclosure cooling
- Panels, MCCs, DIN rail, NEMA/IP enclosures, labeling, and panel hardware
- EV charging, EVSE, DC fast charging, load management, V2H, and V2G concepts
- Electrical safety, lockout/tagout, stored energy, absence-of-voltage verification, PPE, and arc-flash concepts

## Design Philosophy

The interface is intentionally:

- **Simple enough for a beginner**
- **Detailed enough to remain useful to experienced users**
- **Visual where terminal relationships or system flow matter**
- **Progressive rather than overwhelming**
- **Consistent across the app**

The home page groups subjects by category and uses restrained color coding to make a large amount of material easier to scan.

## Safety

This project is educational.

Electrical systems can involve lethal voltage, high fault current, arc-flash energy, stored energy, rotating equipment, batteries, thermal hazards, and automatic restart.

Real installation, testing, troubleshooting, commissioning, and energized work must follow:

- Applicable electrical and safety codes
- Equipment manufacturer instructions
- Site-specific procedures
- Proper lockout/tagout practices
- Correctly rated test equipment and PPE
- Qualified-person requirements where applicable

Diagrams and examples in this project are teaching aids and are **not substitutes for project-specific engineering drawings or equipment documentation**.

## Project Structure

This is primarily a browser-based HTML/CSS/JavaScript project.

- **index.html** — main home page
- **app-enhancements.css** — shared interface and theme enhancements
- **app-enhancements.js** — shared navigation, learning level, favorites, recent pages, progress, and other common behavior
- Individual `.html` files — topic explorers, labs, trainers, calculators, and reference pages

## Running the App

No special build system is required for the web version.

You can:

1. Open `index.html` in a browser, or
2. Serve the repository through GitHub Pages or another static web host.
