Beginner Start Here

A processor follows instructions. It moves data, performs operations, makes decisions, and coordinates the rest of a computer or electronic system.

What is a CPU?

The central processing unit executes instructions and controls data movement. In many systems, the CPU is the main computational engine.

What is a microprocessor?

A microprocessor is a processor implemented as an integrated circuit, traditionally relying on external memory and peripherals for a complete system.

What is a microcontroller?

A microcontroller combines a processor core with memory and peripherals such as timers, GPIO, ADCs, and communication interfaces on one chip.

What is the ALU?

The arithmetic logic unit performs operations such as addition, subtraction, AND, OR, XOR, comparisons, and shifts.

What are registers?

Registers are very small, very fast storage locations inside the processor used for data, addresses, instructions, and intermediate results.

What does the clock do?

The clock provides timing that coordinates processor activity. Clock frequency is important, but it does not by itself tell you how fast two different processors will perform useful work.

In Other Words
Memory holds instructions and data.
The control unit decides what operation happens next.
The ALU and other execution units do the actual computational work.

CPU vs. Microprocessor vs. Microcontroller

CPU

  • The processing engine that executes instructions.
  • Contains execution units, registers, control logic, and usually cache.
  • May be one part of a larger chip or system-on-chip.

Microprocessor

  • A processor implemented as an integrated circuit.
  • Traditionally uses external RAM, storage, and many peripherals.
  • Common in general-purpose computing and larger embedded systems.

Microcontroller

  • Combines CPU, memory, and peripherals on one chip.
  • Often includes GPIO, timers, ADC, PWM, serial interfaces, and flash memory.
  • Common in appliances, vehicles, controls, sensors, and embedded devices.

Cores, Threads, Cache & Clock Speed

Modern processor performance depends on many features working together.

CoreAn independent processor execution core capable of running its own instruction stream.Parallel work
ThreadA sequence of instructions scheduled for execution. Some cores support multiple hardware threads.Instruction stream
CacheSmall, fast memory near the CPU that keeps frequently used instructions and data closer than main RAM.Fast memory
Clock SpeedThe rate of the processor's clock. Higher frequency can help, but architecture and workload determine actual performance.Timing
PipelineBreaks instruction processing into stages so multiple instructions can be in progress at the same time.Throughput
Branch PredictionGuesses which path code will take so the pipeline can keep working before the decision is fully known.Control flow
SIMD / Vector UnitsPerform the same operation on multiple data elements in parallel.Data parallelism
Memory ControllerCoordinates transfers between the processor and main memory; often integrated into modern processors.Memory access
Bus / InterconnectMoves addresses, data, and control information among processor blocks, memory, and peripherals.Communication

8-bit • 16-bit • 32-bit • 64-bit

“Bitness” can describe several related processor properties, so context matters.

8-bitCommon in simple embedded controllers. Typical arithmetic and registers may naturally operate on 8-bit values.0–255 unsigned
16-bitProvides wider arithmetic and address/data handling than 8-bit designs while remaining efficient for embedded control.65,536 values
32-bitVery common in microcontrollers, embedded processors, and earlier generations of desktop computing.Wider data
64-bitCommon in modern general-purpose processors and many higher-end embedded systems, with wider integer registers and address capabilities.Large address space
Processor “bitness” does not always equal address-bus width, data-bus width, instruction length, or every internal register size. Check the architecture documentation for the exact meaning.
