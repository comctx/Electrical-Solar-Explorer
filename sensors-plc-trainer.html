Beginner Start Here

  1. Check the sensor supply and output type first.
  2. Match PNP/sourcing sensors with an appropriate sinking-input arrangement, or NPN/sinking sensors with an appropriate sourcing-input arrangement.
  3. NO/NC changes the logical state, not the sensor's basic sourcing/sinking output style.
  4. When troubleshooting, verify supply, common, output signal, and PLC indication one point at a time.
  5. Actual terminal numbers, commons, and colors vary—use the manuals for real equipment.
