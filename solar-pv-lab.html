Beginner Start Here

  1. Panels in series add voltage.
  2. Parallel strings add current.
  3. Lower irradiance usually reduces available current more than voltage.
  4. Shading one panel in a series string can limit string current.
  5. MPPT and PWM controllers behave differently; this lab uses simplified approximations only.

Safety & Model Limits

This is a simplified learning model. It does not determine string limits, Voc at cold temperature, conductor size, overcurrent protection, rapid shutdown, grounding, combiner requirements, controller ratings, or battery charging settings. PV strings can produce hazardous DC voltage.
