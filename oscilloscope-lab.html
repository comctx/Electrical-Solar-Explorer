Beginner Start Here

  1. Vertical = voltage. Volts/div controls how much voltage each vertical square represents.
  2. Horizontal = time. Time/div controls how much time each horizontal square represents.
  3. Amplitude tells how tall the waveform is.
  4. Frequency tells how many cycles happen each second.
  5. Adjust the controls and watch how the same signal looks different on the screen.
