Beginner Start Here

  1. STOP is normally closed. It passes control power until pressed.
  2. START is normally open. Pressing it energizes starter coil M.
  3. M auxiliary NO closes. It bypasses the released Start button and “seals in” the coil.
  4. Overload OL is normally closed. If it trips, the coil drops out.
  5. M main contacts switch the motor power circuit.
